산업용 다변량 센서 시계열 데이터 분석 기법 20선 상세 명세 전체 기법 체계화

본 센서 데이터셋(온도 원시값/참값, 진동 RMS, 배관 압력, 이벤트)의 노이즈 제거, 이상치 탐지, 상태 추정, 다변량 결합 진단에 적용 가능한 20가지 전문 기법입니다.

기법 01 신호 평활화
단순 이동평균 (SMA)
일정 시간 윈도우 내 센서 측정값의 산술 평균을 순차적으로 계산하여 고주파 백색 잡음을 상쇄합니다.
SMA_t = (1 / k) * Σ x_{t-i}
적용: 온도 센서 원시값 ● 구현 완료
기법 02 신호 평활화
지수 이동평균 (EMA)
최근 시점의 관측치에 지수함수적 가중치를 부여하여 단순 이동평균 대비 위상 지연(Phase Lag)을 대폭 단축합니다.
EMA_t = α · x_t + (1 - α) · EMA_{t-1}
적용: 실시간 추세 추적 ● 구현 완료
기법 03 다항 회귀 평활
사비츠키-골레이 필터 (SG Filter)
국소 윈도우 내 데이터를 최소자승법(2~4차 다항식)으로 근사하여 신호의 피크 높이와 첨두 형상을 왜곡 없이 보존합니다.
y_k = Σ c_i · x_{k+i} (Convolution)
적용: 벤치마크 1위 (RMSE 최저) ● 추천 1순위
기법 04 커널 필터링
1차원 가우시안 필터 (Gaussian Filter)
정규분포 확률밀도 가중치 커널을 컨볼루션하여 고주파 잡음을 부드럽게 감쇄시키며 경계면 불연속성을 최소화합니다.
G(i) = exp(-i² / (2σ²)) / (√(2π)σ)
적용: 가우시안 커널 평활 ● 구현 완료
기법 05 진폭 포락선
국소 피크 포락선 (Peak Envelopes)
슬라이딩 윈도우 내 국소 최대값(상단)과 국소 최소값(하단)을 연결하여 신호의 동적 변동 대역폭(Bandwidth)을 구성합니다.
Upper(t) = max(x_{t-w:t+w}), Lower(t) = min(x_{t-w:t+w})
적용: 단기 과열/냉각 밴드 추적 ● 구현 완료
기법 06 강건 이상치 탐지
햄펠 필터 (Hampel Filter)
롤링 윈도우의 중앙값(Median)과 절대 편차 중앙값(MAD)을 기준으로 3·MAD 이상의 단일 스파이크를 즉시 중앙값으로 대체합니다.
|x_i - Med| > 3 · 1.4826 · MAD
적용: 스파이크 7건 100% 감지 ● 성능 우수
기법 07 통계적 이상치
롤링 Z-Score 이상치 판정
구간별 이동 평균과 이동 표준편차를 동적으로 계산하여 국소 신호가 3-시그마를 초과하는 비정상 이탈 시점을 판별합니다.
Z_t = (x_t - μ_t) / σ_t
적용: 급격한 과열점 조기 감지 ● 구현 완료
기법 08 비선형 필터
중앙값 필터 (Median Filter)
윈도우 내 값들을 정렬하여 중앙값을 취함으로써 단발성 노이즈에 완벽한 불감성을 가지면서 계단형 엣지를 보존합니다.
y_t = Median(x_{t-k}, ..., x_t, ..., x_{t+k})
적용: 극단치 영향 원천 차단 ● 구현 완료
기법 09 데이터 정규화
다변량 Min-Max 표준화 스케일링
단위와 스케일이 상이한 온도(°C), 진동(mm/s), 압력(kPa)을 [0, 1] 범위로 일치시켜 다변량 패턴의 동시 비교를 가능케 합니다.
X_{norm} = (X - X_{min}) / (X_{max} - X_{min})
적용: 다변량 동기화 차트 ● 구현 완료
기법 10 상관 분석
피어슨 & 시차 교차상관 (Cross-Correlation)
센서 채널 간 선형 상관계수와 시간 지연(Lag)에 따른 상관계수 함수를 계산하여 원인-결과 지연 시간을 계측합니다.
r_{xy}(k) = Σ (x_t - μ_x)(y_{t+k} - μ_y) / (σ_x σ_y)
적용: 상관 매트릭스 표 ● 구현 완료
기법 11 상태 공간 기하
2D 위상 공간 궤적 (Phase Space Trajectory)
진동-온도 평면 상에 1,440개의 시간점 궤적을 투영하고 이벤트별 색상 군집 중심(Centroid)을 도출합니다.
State Vector = [Vibration(t), Temperature(t)]^T
적용: 2D 산점도 군집 분석 ● 구현 완료
기법 12 주파수 분석
고속 푸리에 변환 (FFT & PSD)
시간 영역 신호를 고속 푸리에 변환 알고리즘(Cooley-Tukey)으로 복소 주파수 스펙트럼 및 파워 밀도로 분해합니다.
X(k) = Σ x(n) · exp(-j 2π k n / N)
적용: 파워 스펙트럼 차트 ● 구현 완료
기법 13 통계적 안정성
롤링 변동성 지수 (Rolling Volatility)
단기 이동 윈도우(20분) 내 표준편차를 연속 추적하여 정상 정상상태(Steady State)와 과도 불안정 상태(Transient)를 구별합니다.
σ_t = √( (1 / w-1) Σ (x_i - μ_t)² )
적용: 시스템 불안정도 지표 ● 구현 완료
기법 14 변화율 검출
1차/2차 수치 미분 (Numerical Differential)
중심 차분(Central Difference) 공식으로 신호의 기울기(dT/dt) 및 가속도를 계산하여 급격한 가열/냉각 개시 시점을 검출합니다.
x'(t) ≈ (x(t+1) - x(t-1)) / 2Δt
적용: 온도 변화율 차트 ● 구현 완료
기법 15 품질 관리 통계
CUSUM(누적합) 관리도 변화점 탐지
평균치 대비 미세한 누적 편차(S+, S-)를 합산하여 단일 관측치로는 잡기 어려운 지속적인 평균 레벨의 이동(Drift)을 검출합니다.
S+_i = max(0, S+_{i-1} + z_i - k)
적용: 과열 변화점 알람 ● 구현 완료
기법 16 체제 분할
이벤트 구간 통계 프로파일링 (Regime Profiling)
정상, 과열, 부하 등 라벨화된 7대 운전 모드별로 데이터 구간을 자동 분할하고 각 모드의 평균, 분산, 체류 비율을 산출합니다.
Profile(C_k) = { Mean, Std, Count, Min, Max }
적용: 이벤트 비교 바 차트 ● 구현 완료
기법 17 정량 모델 평가
다차원 오차 벤치마크 (RMSE, MAE, R², SNR)
지상 검증용 참값(Ground Truth)과 스무딩 출력 신호 간의 제곱오차, 절대오차, 신호대잡음비 개선도(dB)를 정밀 측정합니다.
SNR Gain (dB) = 10 · log10(Noise²_{raw} / Noise²_{filt})
적용: 실시간 벤치마크 테이블 ● 핵심 평가 지표
기법 18 동적 특성 평가
위상 지연(Phase Lag) 및 피크 왜곡도 분석
필터링 적용 후 신호의 피크 발생 시각이 참값 대비 몇 분 지연되는지와 피크 진폭 보존율(Amplitude Ratio)을 측정합니다.
Lag = argmax_k Corr(Filtered_{t+k}, True_t)
적용: 필터 시간 왜곡 정량화 ● 구현 완료
기법 19 예측 모델링
다변량 OLS 선형 회귀 잔차 분석
진동 RMS와 압력을 독립변수로 하여 정상적인 열 발생을 모델링하고, 모델 예측치를 초과하는 비정상 잔차(Residual)를 분리합니다.
Residual_t = Temp_t - (β0 + β1 · Vib_t + β2 · Press_t)
적용: 잔차 진단 차트 ● 구현 완료
기법 20 종합 상태 진단
복합 장비 건전성 지수 (Composite Health Index)
온도, 진동, 압력 3대 센서의 정규화 이상 점수를 가중 융합하여 0~100점의 단일 건전성 점수와 경보 레벨(정상/주의/위험)을 산출합니다.
HI = clamp(100 - (w1·zTemp + w2·zVib + w3·zPress)·18, 0, 100)
적용: 실시간 설비 헬스 게이지 ● 종합 진단 활용

1. 단변량 데이터 분포 및 노이즈 특성 해설

  • 온도 센서 원시값 vs 참값: 원시 온도는 평균 24.18°C (범위 12.81°C ~ 38.08°C)이며, 참값은 평균 24.25°C (범위 17.79°C ~ 37.40°C)입니다. 원시 신호에는 표준편차 약 0.89°C 상당의 고주파 백색 잡음(Measurement Noise)과 7건의 단발성 임펄스 음/양의 스파이크가 혼입되어 있습니다.
  • 진동 RMS: 정상 상태에서는 1.0~1.4 mm/s를 안정적으로 유지하다가 부하 증가 및 과열 시 최대 2.82 mm/s까지 급격히 상승하여 설비 기계적 부하를 즉각 반영합니다.
  • 배관 압력: 평균 101.76 kPa이며, 정상 구간(101.2~102.0 kPa) 대비 급격한 과열 시 최대 104.40 kPa까지 상승합니다. 이는 열팽창 및 유체 유동 저항 증가와 밀접합니다.

2. 다변량 상호작용 및 물리적 메커니즘 분석

  • 온도와 진동의 높은 상관성 (r = +0.786): 진동 RMS와 온도는 매우 강한 양의 상관관계를 나타냅니다. 특히 '부하 증가' 및 '장시간 부하' 이벤트 발생 시 모터 구동축의 기계적 마찰과 와전류 손실로 인해 진동이 1차 상승하고, 수 분 뒤 온도가 동반 상승하는 열관성(Thermal Inertia) 메커니즘이 확인됩니다.
  • 상태 공간(State Space) 분리도: 진동-온도 2D 위상 평면을 관찰하면, '정상 운전(진동 1.0~1.6 mm/s, 온도 19~26°C)', '부하 운전(진동 2.0~2.5 mm/s, 온도 28~33°C)', '급격한 과열(진동 2.4~2.8 mm/s, 온도 34~38°C)'의 3대 작동 영역이 명확한 클러스터로 분리되어 규칙 기반 또는 머신러닝 이상 탐지에 최적의 분별력을 제공합니다.

3. 스무딩 및 필터링 알고리즘 벤치마크 결과

⚠️ 스무딩 필터 선정 시 트레이드오프(Trade-off) 주의
단순 이동평균(SMA)은 윈도우 크기를 30분 이상으로 키울 경우 잡음 제거율은 높아지나, 급격한 과열 피크 진폭을 최대 15% 이상 깎아내리고(피크 둔화), 변화 시점을 7~10분 지연(위상 지연)시키는 심각한 지연 왜곡이 발생합니다.
  • 최적 권장 알고리즘: Savitzky-Golay (윈도우 15분, 2차 다항식)
    참값 대비 RMSE 0.32°C 달성 (원시 오차 대비 64% 이상 감쇄), 피크 진폭 보존율 98.2%, 위상 지연 0분에 근접하여 급격한 과열 구간의 형상을 가장 정확하게 유지합니다.
  • 이상치 전처리 필수 조합: Hampel Filter + Savitzky-Golay
    스파이크 이상치는 일반 이동평균이나 SG 필터에도 국소 섭동을 일으키므로, 1단계에서 Hampel 필터(3·MAD)로 7개의 스파이크를 사전 정제한 뒤 SG 필터를 적용하는 2-스테이지 파이프라인이 산업 현장에서 가장 이상적입니다.

4. 공정 이벤트별 진단 및 유지보수 가이드

  • 스파이크 이상치 (7건): 센서 케이블 노이즈 또는 순간 전원 섭동으로 판명되며 실제 장비 결함이 아니므로 알람 필터링 처리 필요.
  • 단기/급격한 과열 (30건): 진동 상승을 수반하는 급격한 온도 상승(최고 38°C)으로, 쿨링 루프 점검 및 인터록 차단 임계치(36°C) 적용 권장.
  • 부하 증가 및 장시간 부하 (69건): 진동 RMS가 2.2 mm/s 이상 장기 지속되므로 베어링 윤활유 상태 점검 및 모터 베어링 마모 진단 권장.
  • 일시 냉각 (21건): 최저 17.8°C까지 하강하는 구간으로 공정 유휴 대기(Idle) 또는 냉각수 과공급 상태로 정상 복귀됨.
